# deploy

`deploy/systemd/` holds the **rendered** unit files (`{{REPO}}` replaced with the
checkout path). They are generated by `make install TS=nn` and symlinked into
`/etc/systemd/system/`. Never edit them by hand — edit
`strategies/TSnn_*/systemd/` and re-run `make install`.

Host setup, once: `bin/install-server`. It creates the `trader` user,
`/etc/trading/TSnn.env` (mode 600) per strategy, the venv, and enables the git
hook.

Unit naming is the strategy ID: `TS01-runner.service`, `TS01-weekly.timer`.
`make status` lists every `TS*` unit; `journalctl -u TS01-runner` is the log.

## Moving to Paperclip later

Each strategy already reduces to: one long-running process
(`python -m strategies.<slug>.py.runner`), zero or more scheduled commands
(`… .py.backtest --refresh`), an env file, and a writable `logs/` + `results/`.
That is the whole contract — port those four things and nothing in
`strategies/` changes.
